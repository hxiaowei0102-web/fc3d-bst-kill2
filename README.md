# 福彩3D 新版百十个杀一码（27.6万单双公式池 · 450期单窗口）

**百十个位各杀一码**：每天重跑穷举，为百/十/个位各选一条最优杀码公式，每位置各杀1码。

## 核心算法
- **公式形式**：`(c·F + const) % 10`，F 为单特征或双特征组合（含单双池）
- **公式池**：单特征 + 双特征，约 **276,120 条**
- **选优**：每位置独立，在**最近450期窗口**内选命中率最高者；并列裁决=命中率→公式短→字典序
- **动态重选**：每次 auto_update 全池重跑，公式/杀码逐期可能变化（非固定）
- **单窗口450期**：2026-09-04 起删除 350 期窗口，只保留 450（回测/预测/tracking 统一450）

## 文件
- `engine.py`：CSV 读取 + 期号推断（跨年自适应，非硬编码359）
- `formulas.py`：特征 + 公式流式生成器
- `bruteforce_v2.py`：numpy 向量化穷举（27.6万单双池，单窗口约13s）
- `backtest.py`：固定公式回测 + 下期预测
- `fetch.py`：4 源降级链（URL 集中 DATA_SOURCES 配置区）
- `tracking.py`：每日预测跟踪（jsonl，幂等，样本外）
- `auto_update.py`：云端全自动入口（幂等，无变化零部署）
- `gen_site.py`：生成自包含单窗口网页（含公式库容错）
- `sync.py`：本地↔云端同步（status/pull/push/token）
