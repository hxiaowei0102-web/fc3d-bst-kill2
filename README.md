# 福彩3D 新版百十个杀2码（暴力穷举·近200期）

云端全自动预测：每位置杀2码（6码），只参考近200期数据，暴力穷举最优组合，双套算法切换。

## 线上地址
https://hxiaowei0102-web.github.io/fc3d-bst-kill2/

## 核心算法
- 算法池：3个决策树（参考 D:/百十个）+ 79条固定公式 + 海量线性公式（去重后 47892 个算法）
- 每位置从算法池暴力穷举 2 个算法杀 2 码（碰撞时第二码 +1 兜底）
- 指标：近200期 6杀全中率
- 系统1 87.0% / 系统2 86.0%（12 个算法互不重复）

## 云端自动化
- GitHub Actions cron 三重兜底：北京 22:00 / 23:30 / 01:00
- 多数据源降级：灰鸟API(主) + 17500(http全量) + apihz
- 开奖后抓取 → 期号校验 → 追加CSV → 双套回测 → 生成 predict.json → 部署 Pages

## 文件
- `auto_update.py` 云端更新脚本（抓数据→追加CSV→回测→预测）
- `bruteforce.py` 暴力穷举（本地重跑可再搜）
- `algorithms.py` / `backtest.py` / `engine.py` 算法库与回测引擎
- `best_sets.json` 两套固定组合
- `data/fc3d-history.csv` 历史数据
- `static/` 网页 + 预测数据

> 仅供研究参考，不构成投注建议。近200期命中率为暴力穷举的历史拟合，样本外会回落。
