# 福彩3D 新版百十个杀一码（905万公式池暴力穷举）

**彻底推倒重来**：由「杀2码」改为「百十个位各杀一码」，学百十个杀一码方案重建。

## 核心算法
- **特征体系**：59 个（上期单期 34 + 单期派生 9 + 前2期跨期 16），全部由第 i-1 期及更早数据计算，不偷看未来
- **公式池**：单特征(系数1/2/3/5×常数0-9) + 双特征 + 三特征(系数1/2/3) ≈ **9,053,550 条**
- **选优**：每位置独立，在窗口内（200期 / 300期）选命中率最高者；并列裁决=命中率→公式短→字典序
- **双窗口**：最新200期版 + 最新300期版，网页可切换

- `backtest.py`：固定公式回测 + 下期预测
- `fetch.py`：6 数据源降级链（huiniao/17500/apihz/cwl/55128/8200）

- `sync.py`：本地↔云端同步
